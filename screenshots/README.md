# Great Cliffs Website Screenshots

This folder contains screenshots of all three pages of the Great Cliffs website project.

## Pages Included:

1. **01-home-page.md** - The home/landing page with logo, navigation, and welcome message
2. **02-activities-page.md** - Activities page showing the activity table with all cliff locations
3. **03-contact-page.md** - Contact page with contact information and contact form

## Website Overview:

The Great Cliffs website is a multi-page site for an outdoor recreation park. It includes:
- **Home Page**: Landing page with branding and navigation
- **Activities Page**: Complete table of available activities at different cliff locations
- **Contact Page**: Contact information and inquiry form

All pages feature consistent styling, navigation, and professional design with outdoor imagery.
